
# Firefox, Firefox-ESR Idiomas interfaz & correctores ortográficos - antiX, MX Linux

![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEjpaOz-pGz_wiEZmbTrQACx1K96QK3NaDSAQpN7ZnhOjNX-bhggAUJmlf6SrnbCDo_VRhHHpHlagQBk_ODp5oV2B5fVtqDIkqaY2r3QbL-Y3kKlYffs0NBmbqgoyuVCkHjXC0QvCa-EWpa6CJq7FiqLxPfanqYyk3Sc7PfUbWLzAT1XFTr0Bq6swVHVnko/s1536/portada.jpg)

En antiX y MX Linux no se instala automáticamente el paquete del idioma, y diccionarios de corrección ortográfica, este tutorial es para hacer eso

**Nota:** Además podrá usted instalar herramientas de corrección ortográfica para corregir varios idiomas en el mismo documento

---

### INSTALANDO LENGUAJE DE LA INTERFAZ GRAFICA - Desde paquetes en los repositorios

En antiX y MX Linux hay dos paquetes de Firefox, son estos:

* firefox
* firefox-esr

puede usar cualquiera de los dos

**firefox.-** En MX Linux y antiX hay paquetes para los idiomas incluido el español, encontrarlo en Synaptic:

firefox-l10n-xpi-es-es

![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEhet05107868GmaLnV8lS77Lb8IO5ZCVIIhzridTa-ygQi-35G3Qctuqgmi9f14lYjaTzsFGdtgqb9elPKxmlXrKq6SicdK2Z1Eg6XWfVwaF8N2MDC9xdKFC2PY_VLVH1RZ92Bw2bjeWMo/s16000/20201005-112231.png)

**Nota:** Allí hay otros idiomas

también se puede instalar desde la terminal:

**Para Firefox**

```bash
sudo apt install firefox-l10n-xpi-es-es
```

**Para Firefox_ESR**

el paquete se llama:

```bash
sudo apt install firefox-esr-l10n-es-es
```

Ahora reiniciar el Navegador

Luego, abrir el Navegador e ir a:

**Edit > Settings**

por defecto está el inglés:

![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEg4hXTYali2MzzLdAqlRsH60i2OdxPyp3ksv-lmqWQ-Mb8QrDK7B4-i9AEM0qHQY2j6y2dcLco0VK9BJddH56RMHgtlPPWY-x_XFlDhLweQfxNKWVdk829oAMXyg-epNsJFv-qZRIq5MKABTcv1sE_ksiyNw9pztn9i7jneZxPPbpX2CsLX_0cMURxeInw/s16000/Seleccionar%20el%20lenguage%20en%20espa%C3%B1ol%20para%20Firefox.png)

y marcar en:

**Language**

seleccionar el:

**Español**

## INSTALANDO DICCIONARIOS DE CORRECCIÓN ORTOGRÁFICA DE DIFERENTES IDIOMAS

Si tu necesitaras además del español otros idiomas más, se pueden instalar:

Presionar la tecla "**Alt**" e ir a:

**Editar > Configuración**

busca:

**Revisión ortográfica**

y da clic en:

**Descargar diccionarios**

![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEimWTLLoUHxU1-DOOkoP9ICwi7ffgRMzWA04HRzYShEGQ7L7yyVYZS17d_J3mv6nUzXPoxOkQl_96inlxwoapWgyT-H8b9afeHfI76VNKpamil4OwFc12eXfbSK_3rwuxulUqSLtVn6C34jJcmpsaRUeYjmuBpZaORWANPdio_V0cyJSg1RBhyW52W13wM/s866/Firefox%20-%20Editar_Configuración%20-%20Revisión%20ortográfica.png)

y te llevará a:

**Diccionarios y paquetes de idiomas**  
[https://addons.mozilla.org/es-MX/firefox/language-tools/](https://addons.mozilla.org/es-MX/firefox/language-tools/)

allí en la **columna de la derecha** están los diccionarios:

![](https://blogger.googleusercontent.com/img/b/R29vZ2xl/AVvXsEiupmsiC3TteOTmK2DJw6P2qmQmKvSwwx6e96GlDEUjzyU335qp6vbhNONvsetOqS6T3iopYR4lUsXfOyJxp35CvJbd_TvrqL2-7T_iqLfymJgNVW0HqVaSyRXlGqXksHRA9UukWoO3GsM/s16000/20200917-093438.png)
