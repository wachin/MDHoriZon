
# Paquetes de desarrollo para paquetes deb en MX Linux

En MX Linux viene una herramdienta llamada `MX Install`, allí buscando la palabra:

```
deb
```

aparece:

```
deb packaging tools
```

lo marco y esto instala los siguientes paquetes de desarrollo:

```bash
pbuilder debhelper libparse-debcontrol-perl devscripts dh-make fakeroot build-essential dpkg-dev binfmt-support qemu-user-static 
```
