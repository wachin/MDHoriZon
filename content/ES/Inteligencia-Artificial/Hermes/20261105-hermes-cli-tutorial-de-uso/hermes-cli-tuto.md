


Para instalar hermes en Linux, macOS, Windows:

https://hermes-agent.nousresearch.com/docs/getting-started/installation


para navegar entre sesiones anteriores:

```bash
hermes sessions browse
```

para cambiar los modelos poner:

```bash
hermes model 
```

pero la lista que muestra no está desactualizada, por eso siempre hay que revisar ejemplo en NVIDIA NIM cuales son los modelos que están activos y no han caducado: https://build.nvidia.com/
